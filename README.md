# IGCSE Accounting 4AC01 — Past Paper Map

Interactive dashboard of every Pearson Edexcel International GCSE Accounting (4AC01) question paper, May 2019 – May 2026: 42 papers, 847 sub-questions, 3,150 marks, classified by topic against the official specification.

**Live:** see repository Pages URL.

- `index.html` — single-file dashboard (filters, heatmap, topic ranking, command-word tally, question browser, PDF extraction)
- `4AC01_Papers/` — the 42 source question papers as PDFs, read by the extraction feature
- `mcq/` — Section A MCQ bank: all 210 Paper 1 multiple-choice questions (May 2019 – May 2026, incl. R papers) with click-to-check answers, explanations and topic filters. `mcq/mcq_bank.json` holds the same data. Answers are prepared by Vertical Horizon, not Pearson's published mark schemes.
- `flashback/` — IGCSE Flashback: the full O Level revision deck for exam week (142 slides, 17 chapters), with step-by-step ledgers, past-paper style documents, quizzes and a presenter view for the projector
- `anchors.json` — pixel positions of every question number, sub-part label and question end on the scanned pages (Tesseract OCR), used to cut individual sub-parts

Built for **Vertical Horizon · ACCOUNTING by TAK**, Dhaka.
